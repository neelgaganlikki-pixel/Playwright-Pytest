# 14. LOCATOR STRATEGY

Prefer Playwright's reliable locator strategies:

```python
page.get_by_role()
page.get_by_label()
page.get_by_placeholder()
page.get_by_text()
page.get_by_test_id()
```

Use CSS when necessary.

Use XPath only when genuinely required.

Avoid:

```text
Long XPath
nth-child()
Generated CSS classes
Fragile DOM paths
Random dynamic attributes
```

Choose locators based on the actual OrangeHRM DOM.

---

# 15. SYNCHRONIZATION

Use Playwright's built-in auto-waiting.

Do not use:

```python
page.wait_for_timeout()
```

as a default synchronization mechanism.

Use condition-based synchronization such as:

```text
Element visible
Element enabled
URL changed
Dashboard displayed
Login page displayed
```

Use appropriate Playwright assertions.
